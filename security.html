Security Policy

SteadyGantt for Jira · Effective August 13, 2026

Architecture in one sentence: SteadyGantt runs entirely on Atlassian's Forge platform with no servers, databases, or infrastructure of its own — the platform technically prevents it from sending data anywhere outside Atlassian.

Platform security

  • No egress by design. The app declares no external endpoints. Atlassian's Forge runtime enforces this at the network level; the production version qualifies for the Runs on Atlassian program.
  • No secrets handled. The app never asks for passwords, API tokens, or Personal Access Tokens. All Jira access happens through Atlassian's managed OAuth, as the logged-in user, within the scopes approved by your admin at install time.
  • Minimal scopes. read:jira-work (draw the chart), write:jira-work (apply only the date changes you explicitly confirm), storage:app (save your view preferences in Atlassian-hosted Forge storage).
  • No third-party code at runtime. The UI is a single self-contained bundle — no CDN scripts, no analytics SDKs, no trackers.

Data handling

  • Issue data is read through official Atlassian APIs and rendered in your browser. It is never transmitted to the developer or any third party.
  • Writes happen only after you review and confirm an explicit change summary, touch only the date fields you checked, and every sync can be undone in one click.
  • Stored data is limited to per-user view preferences (in Atlassian-hosted Forge storage) and a task-list cache in your own browser. Details in the privacy policy.

Development practices

  • Every release passes an automated regression suite (including write-back safety assertions: payloads contain only confirmed fields; undo payloads restore exact previous values) and a rendering performance budget enforced in CI.
  • Dependencies are minimal by policy (no UI framework, no runtime dependencies beyond the official Atlassian Forge SDK) to keep the supply-chain surface small.

Reporting a vulnerability

If you believe you've found a security issue, email steadygantt@outlook.com with steps to reproduce. You'll get a first response within 24 hours. Please allow a reasonable window for a fix before public disclosure; good-faith research is welcome and will never be met with legal threats.
